# CardVault

Готовый Android-проект электронного кошелька для бонусных карт.

Сейчас есть:
- Пятёрочка и Магнит как стартовые карточки
- добавление собственных карт
- название, код/номер карты и цвет
- локальный экран кошелька
- Material 3 интерфейс

## Сборка
Открой проект в Android Studio и выполни:
`./gradlew assembleDebug`

APK появится в:
`app/build/outputs/apk/debug/app-debug.apk`

Важно: это первая рабочая версия интерфейса. Сканирование камеры, генерация настоящих QR/штрихкодов и экспорт/импорт Pass2U можно добавить следующим этапом.
